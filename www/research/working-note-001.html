Working Note 001 / under construction

Reversible representations
before the model.

A construction note, not a finished paper: what happens if the representation layer is treated as an explicit reversible machine rather than an invisible preprocessing footnote?

OKCompressordraftversion intentionally unstable

Abstract

OKC explores reversible transformations between raw data, structured token/ID streams, sidebands and model-facing representations. The central engineering constraint is exact recovery; the research question is whether structure exposed before entropy coding or prediction can improve inspectability, vocabulary pressure, latency, memory or downstream modelling in bounded regimes.

1. Construction premise

A representation should be measurable as a machine: input, state, output, inverse, delay, memory and failure conditions. Compression ratio alone is not enough to describe its deployment value.

2. Public proof trail

Rare1, Redumb/DUMB, IDStream and related public artifacts are partial evidence, not completion claims. The useful record includes what reconstructs exactly, what is benchmark-specific and what remains open.

This page is deliberately incomplete. Claims graduate only when a runnable receipt exists.

3. Current questions

  • Which reversible transforms admit bounded-delay streaming?
  • When do sidebands reduce active representation pressure enough to matter downstream?
  • Can deeper structural analysis teach a smaller bounded runtime?
  • What should be stored or transmitted when the consumer is a model rather than a human parser?

4. Commercial boundary

The public working note is not the private research dossier. Private prototypes, deeper architecture, scoped transfer and commercial implementation are separate engagements.
