Independent Working Note / DOE-001 / under construction

doe:
a reversible experiment, left unsterilised.

A reproducibility-first note for a small coder: specification before prestige, reconstruction before ratio, failure cases kept visible.

STATUS : construction visible
IMPLEMENT. : pending canonical release
CLAIMS : none until reproduced
BENCHMARKS : enwik fixtures planned
RESTORE : byte equality required

Abstract

This note will state only what the released implementation and fixtures support. No compression ranking is inferred from a single corpus.

Method

Format definition, encoder/decoder contract, exact reconstruction receipt, environment, corpus hashes, command lines and observed measurements.

Evaluation

Start with reproducible enwik fixtures and per-file tests. Multi-file/container behaviour is a separate experiment, not silently folded into the coder.

Adverse results

Inputs where the coder loses, expands, slows down or behaves awkwardly stay in the note. Negative results are part of the artifact.

Academic theatre inversion: the artifact is primary; the paper earns authority only by making the machine easier to falsify.
