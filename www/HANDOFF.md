# OKC storefront — fixed-scope visual handoff

Goal: polish the existing static HTML/CSS/JS without changing product claims, licences, URLs or information architecture.

## Deliverable
- Return one static folder that opens with `python3 -m http.server`.
- No framework, build chain, CMS, analytics, cookies, account system or database.
- Desktop + mobile visual polish.
- Preserve horizontal artifact-card rail on mobile.
- Preserve `mailto:` routes and external GitHub links.
- Do not add claims such as “secure”, “unbreakable”, “SOTA”, “best compression”, or performance numbers not already supplied.
- Do not request private product source code. The web job receives only public copy, screenshots, demos and static assets.

## Visual direction
Alien research shelf + restrained terminal / PS3-XMB calm. Dark, spacious, tactile, slightly strange. Avoid SaaS gradients, startup stock art, dashboard cards everywhere, “AI generated” gloss, or crypto-finance aesthetics.

## Interaction
Subtle hover / focus / horizontal mobile scroll only. Fast and boring technically.

## Communication
Fixed-price async job. Questions in one written batch. No recurring calls required.
