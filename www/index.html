PROOFS / BENCHES

Claims ship with receipts.

Benchmarks are evidence for a particular build, corpus and machine—not universal rank claims.

reconstruction

Exact restore

Input hash, encoded hash, decoded hash and byte equality where reversibility is claimed.

fixtures

Reproducible corpora

Small pathological fixtures first; enwik-style runs where useful; command lines and toolchain recorded.

adverse results

Keep the losses

Expansion, slow paths and awkward inputs remain visible. A failed hypothesis is still an artifact.
